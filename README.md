## 🚀 代码实践项目

### 1. 并发登录压力测试与TCP握手分析 (Python / Requests / Wireshark)
- **场景**：模拟游戏开服或大版本更新时，大量玩家同时涌入登录的场景。
- **实现**：使用 `ThreadPoolExecutor` 多线程模拟100个用户同时发送 POST 登录请求，统计成功率和响应时间分布；对比多进程与多线程在 IO 密集型任务下的表现。
- **网络分析**：结合 Wireshark 抓包，分析并发请求下的 TCP 三次握手过程，验证连接建立的可靠性。
- **目录**：`/concurrent-login-test/`

### 2. 接口测试基础脚本 (Python / Pytest / Requests)
- **场景**：日常接口回归测试。
- **实现**：掌握 GET/POST 请求发送、Cookie 关联处理（如登录态保持）、JSON 响应断言。
- **进阶**：结合 Pytest 编写测试用例，生成 Allure 测试报告。
- **目录**：`/api-test-basics/`
